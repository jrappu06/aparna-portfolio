# Aparna J R Swamy - Portfolio

A static portfolio website. All CSS and JavaScript are inside `index.html`.
Fonts load from Google Fonts. No build step is needed.

## Publish on GitHub Pages
1. Create a new public repository on github.com (for example `my-portfolio`).
2. Click "Add file" > "Upload files" and upload `index.html` and `README.md`.
3. Click "Commit changes".
4. Go to Settings > Pages.
5. Under "Build and deployment", set Source to "Deploy from a branch".
6. Choose branch `main` and folder `/ (root)`, then click Save.
7. Wait 1-2 minutes. Your site will be at https://YOUR-USERNAME.github.io/my-portfolio/
